# Bank Account App

Ek simple command-line bank account program, Python me bana hua.

## Features
- Deposit aur withdraw
- Balance dekhna
- Account data JSON file me save aur load hota hai
- Galat input aur kam balance par custom exceptions se error handling

## Concepts jo use hue
- OOP (class, object, methods)
- Exception handling (try/except/finally, custom exception, raise)
- File handling aur JSON

## Kaise chalayein
Command Prompt me ye likho:

    python bank_app.py

## Menu
1. Deposit
2. Withdraw
3. Balance dekho
4. Save aur Exit
